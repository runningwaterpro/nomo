# 图表图片复制

Mermaid 图表卡片与全屏视图都提供「复制图片」按钮。复制结果是按浅色导出主题重新渲染的 PNG：2 倍像素、长边不超过 4096、白底、8px 内边距，不含工具栏、缩放条等界面元素。剪贴板只写入图片格式，不附带 HTML 或纯文本。

## 验收步骤

在 Windows 免安装包中执行：

1. 打开 `sample.md`，滚动到 Mermaid 图表。
2. 使用浅色主题，点击图表工具栏的复制按钮，确认按钮显示对勾；分别粘贴到 Word、钉钉、微信，确认显示为图片且不带工具栏。
3. 切换到深色主题，再次复制并粘贴到 Word，确认图片为浅色背景、文字可读。
4. 连续点击两次复制，确认第二次立即完成；修改图表源码并退出编辑后复制，确认得到新内容。
5. 打开全屏视图，缩放到 150% 后复制，粘贴后确认得到完整图表而非局部。
6. 导出 Word，确认文档中的 Mermaid 图片与改动前一致。
7. 打开 Quick Look 预览，确认全屏查看器不出现复制按钮。

## 已知限制

- 数学公式、代码块、表格与整篇文档暂不支持复制为图片。
- 图表编辑态的预览工具栏暂不提供复制入口。
