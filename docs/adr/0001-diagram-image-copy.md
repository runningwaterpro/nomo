# ADR-0001: 图表图片复制固定浅色导出主题并只写 PNG

- 状态：已采纳
- 日期：2026-10-29

## 背景

用户需要把 Mermaid 图表粘进 Word、钉钉、微信等外部应用。三个约束决定了实现方式：

- 剪贴板同时包含图片与 HTML 时，Word 和钉钉优先取 HTML，粘贴结果是文本而不是图片。
- 屏幕可能使用深色主题，直接截屏贴进白底文档不可读。
- 若按图表实例缓存图片，内存会随文档内图表数量线性增长。

## 决策

1. 复制只写 `image/png`，不附带 HTML 或纯文本。
2. 复制图始终按浅色导出主题重新渲染，与 Word 导出共用同一光栅化服务。
3. 输出 2 倍像素、长边不超过 4096、白底并保留 8px 内边距，不含工具栏等界面元素。
4. 使用模块级单槽缓存：键为源码 + 导出参数 + 主题，单张超过 4MB 不缓存，编辑器销毁时清空。

## 影响

- 深色主题下复制图与屏幕不一致，这是有意选择，换取粘贴到白色文档后的可读性。
- 超大图表会降采样，避免生成难以粘贴的巨型图片。
- 缓存只保留最近一次；重复复制同一张图即时完成，切换图表后重算。
